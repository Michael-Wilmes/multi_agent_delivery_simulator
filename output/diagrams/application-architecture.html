Runtime flow

Startup validates configuration and creates the graph, agents, and services. The UI sends commands and timed ticks to the engine. The engine coordinates agent actions, graph-based movement, task lifecycle, and deadline-based auctions. Snapshots feed rendering; the KPI recorder persists task, contract, and per-tick data to CSV.

Routing and bidding

Agents estimate delivery bid cost with Manhattan distance. The engine moves agents across graph neighbors and uses BFS distances to guide assigned deliveries. These are separate responsibilities.
